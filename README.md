Описание программы
Кратко: консольное приложение для управления заметками. Позволяет создавать, читать, редактировать, удалять заметки, фильтровать по тегам и дате, выполнять отмену действий (undo). Сохраняет заметки в JSON. Имеет простую полиморфную модель заметок (TextNote, VoiceNote).
Требования для запуска

- Python 3.8 или выше
- Внешние библиотеки не требуются

##Как запустить


git clone https://github.com/твой-логин/notebook-organizer.git
cd notebook-organizer
python main.py


##Как пользоваться

1. При запуске появляется меню с пунктами:
1 — List (показать все заметки)
2 — Create (создать заметку)
3 — Read (прочитать заметку по индексу)
4 — Update (обновить заметку)
5 — Delete (удалить заметку)
6 — Filter (фильтрация по тегу или дате)
7 — Undo (отмена последнего действия)
8 — Save (сохранить в notebook.json)
9 — Quit (выйти)
2. Выберите пункт, введите запрошенные данные.
3. Title и Text не могут быть пустыми при создании.
4. Теги вводятся через запятую (опционально).
5. Дата хранится в ISO-формате; фильтрация по дате поддерживает префикс YYYY-MM-DD.
6. Данные сохраняются в notebook.json при выборе "Save" или по подтверждению при выходе.

Примеры использования

- Создать текстовую заметку: выбрать 2, тип "text", ввести Title, Text, Tags.
- Просмотреть все: выбрать 1.
- Прочитать заметку №3: выбрать 3 → ввести 3.
- Обновить заметку №2: выбрать 4 → ввести 2 → ввести новые значения или оставить пустым для сохранения старых.
- Удалить заметку №1: выбрать 5 → ввести 1.
- Фильтровать по тегу "work": выбрать 6 → t → ввести work.
- Фильтровать по дате 2026-05-01: выбрать 6 → d → ввести 2026-05-01.
- Отменить последнее действие: выбрать 7.
